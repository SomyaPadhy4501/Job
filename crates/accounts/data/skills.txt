# Skills the resume matcher recognises, one per line:
#
#   Canonical name | more aliases | group | role families
#
# - The canonical name is matched too, ignoring case. Aliases are separated by
#   commas and also ignore case.
# - An alias written `=Go` is matched with exact case and counts only when
#   another skill is mentioned nearby (a list or "Go or Java"), because the
#   word is common in plain English. When the canonical name itself is in the
#   aliases as `=Name`, it is not added again ignoring case.
# - Skills in the same group earn partial credit for each other (a job asks
#   for AWS, the resume shows GCP). Leave the group empty when they shouldn't.
# - Role families are the ones in rank.rs: ai, data, platform, backend,
#   frontend, fullstack, mobile, security, embedded, qa, swe.
